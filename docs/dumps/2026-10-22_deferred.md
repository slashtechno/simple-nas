# Deferred work (2026-10-22)

Things discussed during the maintainability refactor and left for later. The decisions made are in `2026-10-22_refactor.md`.

## Renovate (pinned image versions)
- Problem: `crafty_version: latest`, the restore helper's `gitea/gitea:latest` and Immich's `release` tag can change under a redeploy.
- Idea: pin each to a real version, and let Renovate (a bot that opens pull requests when a newer image exists) bump `*_version:` keys in `vars.yml`/role defaults through a regex manager.
- Why deferred: the owner has not decided; it adds a GitHub bot and pull requests to merge.

## Bitwarden vault-password script
- Problem: `--ask-vault-pass` means typing the vault password on every run.
- Idea: a script set as `vault_password_file` in `ansible.cfg` that prints the password with `bw get password <entry>`. Needs the `bw` CLI installed and unlocked on the laptop.
- Why deferred: the owner chose to wait. The vault password itself is already in Bitwarden.
