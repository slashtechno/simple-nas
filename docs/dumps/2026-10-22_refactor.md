## Decisions

| ID | Decision | Why |

| D1 | Work on a branch, not `main` | skill safety rule; owner can fast-forward |
| D2 | Shared compose helper is a standalone role, not `common` | `common` depends on `geerlingguy.docker`; including it would reinstall Docker per role |
| D3 | Helper used only by roles that are identical today | a helper with 5+ parameters is worse than the copy |
| D4 | Superseded: compose-only roles (immich, gitea, homebridge, crafty) lost their handlers | `docker_compose_v2 state: present` already recreates a changed container, so the restart handler was redundant. Roles with config files (copyparty, garage, pics, backup-status) keep theirs |

| D6 | Enable-flag defaults stay in `site.yml` | it is the only place a role is gated |
| D7 | Teardown keeps one tagged block per service, each now `import_tasks: teardown_service.yml` | `--tags copyparty,garage` still works because imports propagate tags; `include_*` does not |
| D8 | Lint rules skipped only with a written reason | a config that skips everything is not a gate |
| D9 | Role `defaults/` for single-role knobs; the `| default(...)` copies in templates were removed | three copies of one default (vars, example, template) had already drifted |

| D13 | Postgres dir ownership moved from storage to the immich role | the role that needs uid 999 should set it |
| D14 | "Snapshot Deck" read as the backup-status dashboard (`index.html` title); left unchanged | no echoed line, log name, tag or dump name it parses was altered |
| D15 | Local backup lists `[main_drive, fast_drive, service_dumps_dir] | unique` | today identical to the old command line (same snapshot group); keeps service data covered after the drive split |
| D16 | Cloud script keeps one snapshot per path | `forget` groups by path; merging calls would orphan the existing groups |
| D17 | Removed dead cloud code: `SKIP_PATHS` (only matched the `gitea_data_dir` entry, which is also removed), `~`/`$USER` expansion, `BACKUP_PATHS_FILE` override and cron env | Ansible renders real paths; Gitea still reaches the cloud through its dump |
